# Pricing & Monetization

## Pricing principle
Pricing should be anchored to measurable value protected or recovered.

## Possible consumer structure

### Free
- Manual uploads
- Limited watchlist items
- Basic analysis

### Personal
Indicative range: ~$8–10/month
- Email monitoring
- More/unlimited watchlist items
- Renewal/deadline alerts
- Document history

### Pro
Indicative range: ~$19–25/month
- Agent actions
- Refund/cancellation assistance
- Negotiation workflows
- More automations
- Priority handling

### Family
Indicative range: ~$25–35/month
- Multiple household members
- Shared household vault
- Shared obligations
- Household assets and documents

## Transaction / recovery monetization
For high-value recoveries, consider optional performance pricing such as:
- Fixed recovery fee
- Percentage of recovered money

Example:
> We found $720 you may be entitled to. Recover it for $29 or 10%.

## SMB / Enterprise
Use custom plans based on:
- Number of users
- Number of monitored obligations/contracts
- Integrations
- Workflow volume
- Governance requirements
- Data controls
- Support requirements

Enterprise plans should be commercially customized, not custom code forks.

## Pricing metrics to test
- Per user
- Per household
- Per monitored item
- Per organization
- Usage/action volume
- Recovery-based fee
- Hybrid subscription + usage/recovery

## Value metric
Make ROI visible:

> You paid us $X. We protected/recovered $Y.

This should support both retention and willingness to pay.
